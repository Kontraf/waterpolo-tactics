# Water Polo Tactics Board

An interactive pool diagram for drawing out plays. Drag the six dark players, the six white players and the ball into position. It works with a mouse or a finger on a phone.

**Live:** https://kontraf.github.io/waterpolo-tactics/

## What it does

- Drag and drop players and the ball anywhere in the pool.
- **Reset Positions** puts everyone back in their starting places.
- Works with touch, so it can be used on a phone.

## Run it

No build step. Open `index.html` in a browser, or serve the folder with any static server.

## Built with

HTML, CSS and JavaScript with touch and mouse events.
